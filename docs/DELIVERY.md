## 仍然存在、且不因"已部署"而消失的边界

1. **安全**：公网是 HTTP；没有成熟的用户认证、角色授权、租户隔离和网关限流。`APP_ENV=prod` 只是配置值，不是安全开关。禁止用它处理真实持仓、账户、密钥或受限第三方数据。
2. **数据能力**：扶摇主源覆盖 A 股/指数，港股/美股（如"京东"）会正确降级为"证据不足"；`get_financials` 只到利润表**总量**，没有经核验的连续三年产品/业务分部附注，因此不能宣称已完成"收入架构（分部占比）变化"研究。
3. **成本**：云端未配置模型单价，`cost_total=0` 只表示未计价（看 `tokens_total`/`llm_calls`），费用上限类停止规则此时不可信。
4. **iFinD MCP**：单点调用已验证，但尚无"一次完整 LLM Run 内含 MCP 取证"的证据；云端当前返回 `401`。
5. **审批**：只有计划审批（`plan`）有自动触发点；`expensive_tool` 与 `final_review` 仅有接口。
6. **持久化**：SQLite 单实例 + 持久卷；不支持多副本或多实例共用单文件库。数据库迁移前先备份。

## 云端运维要点（候选人执行）

1. 改代码或改配置后**必须重启对应后端进程**；页面刷新不会加载新后端代码。
2. 前端 `NEXT_PUBLIC_API_BASE` 在**构建时**写入浏览器包，改动后必须重新构建。
3. 密钥与令牌只经受限环境变量或受保护文件注入，不入镜像、不入仓库、不写入日志与截图。
4. 需要演示费用闸门时，先配置 `LLM_PRICE_INPUT_PER_MTOK_CNY` / `LLM_PRICE_OUTPUT_PER_MTOK_CNY`。
5. 演示与录屏使用**A 股标的**（如 `300750.SZ` 宁德时代、`600519.SH` 贵州茅台），避免用港股/美股目标做"主链路展示"。
