2. 给 SQLite 单实例配置持久卷、备份和恢复演练；不同实例不得共享单文件数据库。
3. 通过受限环境变量注入已授权的数据/模型密钥；不要在镜像、仓库或公开日志中存储。前端 `NEXT_PUBLIC_API_BASE` 构建时必须是公网 HTTPS 同源地址。
4. 当前 API 没有完整的公网用户认证/租户隔离；对外演示前落实访问控制、速率/并发限制和账户级费用上限，验证 SSE 与 JSON POST 不受代理阻断。
